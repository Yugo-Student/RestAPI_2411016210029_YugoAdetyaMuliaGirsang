\# REST API CodeIgniter 4 \& JSON Parsing Flutter (CRUD UMKM)



Proyek implementasi REST API menggunakan CodeIgniter 4 (Docker) dan konsumsi API menggunakan Flutter (`http` \& `GetX`).



\## Struktur Proyek

\- `backend-ci4/` : REST API CodeIgniter 4 (CRUD data UMKM + CORS)

\- `frontend\_flutter/` : Aplikasi client Flutter dengan GetX

\- `docker-compose.yml` : Konfigurasi container PHP 8.3, MySQL 8.0, dan phpMyAdmin
